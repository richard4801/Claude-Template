# Suite looks (palettes and film stocks)

`palettes.json` and its `.cube` files are generated by `server/api/scripts/suite-looks.ts` (workstream 1, the video suite).
Looks name them as `"palette:<id>"` (plans/video-editor.md "Looks"). The folder exists even without them so the Mac app's
`palettes` resource folder always builds; with no `palettes.json` there are simply no suite looks.
