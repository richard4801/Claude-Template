# Checking [rules 27–31]
- Before upload: a sheet over a flat colour; zoomed consecutive frames for flicker; original / composite / matte side by side at 2×; a matte at the magnification it will be shown at.
- In MUSE: exact frames one at a time; a frame straight after an asset swap can show the old state — ask twice; several at once fall back to approximate.
- Check the last frames of a move, not only the middle; compare with the previous version side by side.
- Every build script carries a self-check (frame count, geometry at the end frame, rectangles inside the frame). They caught real faults six times.
- Stills prove placement, not feel. Feel is the owner's play at speed.
- Verifying cost time on every trial (approximate frames, asset still loading). Prefer watching the edit itself.
