# Studio prototype

- **Live clickable prototype:** https://claude.ai/artifact/5jmh6Z6riLhAnciXf7Jkb7 (private; share it from the page's Share menu).
- `muse-studio.template.html` is the source. The character images are not stored in git: the `/*IMGS*/{}` placeholder gets replaced with small inline thumbnails when the page is built for publishing.
- "Muse Studio" is a working name.
- Covers: Models (roster, profile, identity refs, outfits, never-add), Create (5-step wizard, 13 look settings), Photoshoot (scene, camera, light, grade, realism, output), Video (source checks, consent, engine, steps 4–30 default 10, background, audio and lip sync, live time/cost estimate, prompt preview), Jobs (queue, cost, test vs final gallery).
