# Windows, strips, panels [trials 38–42, 53–58, 74–77, 120]
- **Core rule:** a window previews the shot it opens into, shown in place and unscaled, playing the 0.3 s before that shot's in-point. The "open to full" is then a plain cut with continuous motion — no mask animation needed. [38, 54]
- Repeat the idea, vary the shape: the same band every bar looked like one trick → new shape per bar (band, figure-first, three slats, diagonal stripe). One generic build where a shape is a list of rectangles. [55, 56]
- One idea per moment: a strip showing a third shot for 0.3 s was one too many. [53, 54]
- One stage per note; count notes before choosing the number of panels; when a panel goes, give its note to the next move. [40, 74]
- A second window showing a crop of him read as two of him. A panel showing only sky is useless. [76, 77]
- Read back "the next clip" with its timecode — an idea was once built at the wrong bar. [57, 58]
- Templates: `window-open-next`, `subject-first`, `diagonal-stripe`, `diagonal-stripes-pair`, `band-behind-subject`, `panel-pile`, `burst-out-card`.
